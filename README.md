# Regional-Sales-Performance-Analysis-and-Visualization
Regional Sales Performance Analysis using Microsoft Excel, Pivot Tables, Pivot Charts(Bar, Pie, Scatter, Stacked charts &amp; etc) and Interactive Dashboard with Slicers.

1.Project Overview

  This project focuses on analyzing regional sales data using Microsoft Excel to identify revenue trends, profit performance, and business growth opportunities across different regions. The analysis was performed using Excel's data analysis and visualization features to support data-driven decision-making.

2.Objective

    Analyze sales performance across regions.
    Identify top-performing and underperforming regions.
    Evaluate revenue, profit, and sales trends.
    Create an interactive dashboard for business insights.

3.Dataset Information

  The dataset contains 4,000 sales records with the following fields:

    Order ID
    Order Date
    Region
    Product Category
    Sales Amount
    Quantity Sold 
    Discount Percentage
    Profit
